# Load this folder into CFAgent Lite

CFAgent Lite only needs `family-health/`.

```text
templates/family-health/  →  /workspace/templates/family-health/
```

Then start a new session and enable toolkit **Family Health**.

These files are prompts, not tools. They do not grant runtime capabilities. Runtime is [cfagentlite](https://github.com/jstdlee/cfagentlite).

Read `family-health/00-router.md` first.
